# Contact-Book

**Overview**

A command-line contact management application developed in Python. The application allows users to create, search, view, update, and delete contacts.

**Current Features**

- Add contacts
- Search contacts by name
- View saved contacts
- Delete contacts
- Update contact information
- Input validation for names and phone numbers

**Technologies**
- Python

**Future Improvements**

- Implement data persistence using JSON so contacts remain available after closing the program.
- Improve input validation and error handling.
